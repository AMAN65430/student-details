Deliverable 6: Explanation of Religion–Caste Dropdown Logic

The Caste dropdown is initialized in a disabled state. When the user changes the Religion dropdown, an event listener immediately resets casteSelect.innerHTML = "" and clears any previously selected value. It then checks the strict mapping dictionary: if Religion === "Hindu", it populates only ["General", "OBC", "SC"]; if Religion is any of ["Muslim", "Sikh", "Christian", "Jain", "Parsi"], it populates only ["Minority"]. Before generating the PDF, validateReligionCastePair() re-verifies that the selected Caste is legally permitted for the selected Religion.
